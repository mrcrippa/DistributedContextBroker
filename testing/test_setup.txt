 - five brokers:

    broker1:  broker1_id, addr: 127.0.0.1, port: 51000
    config_file: broker_config_file_broker1
    neighbors: broker2_id and broker3_id

    broker2:  broker2_id, addr: 127.0.0.1, port: 52000
    config_file: broker_config_file_broker2
    neighbors: broker1_id

    broker3:  broker3_id, addr: 127.0.0.1, port: 53000
    config_file: broker_config_file_broker3
    neighbors: broker1_id, broker4_id and broker5_id

    broker4:  broker4_id, addr: 127.0.0.1, port: 54000
    config_file: broker_config_file_broker4
    neighbors: broker3_id

    broker5:  broker5_id, addr: 127.0.0.1, port: 55000
    config_file: broker_config_file_broker5
    neighbors: broker3_id

 - two context providers (test_context_provider_kaiserslautern and test_context_provider_porto)
    - test_context_provider_porto sends its data to broker5
    - test_context_provider_kaiserslautern sends its data to broker1

 - two context consumers (test_context_consumer_porto and test_context_consumer_kaiserslautern)
    - test_context_consumer_porto subscribes in broker2 to data generated by test_context_provider_porto
        - since the data from test_context_provider_porto is in broker5, broker2 will search for the data in the system
          and the subscription from test_context_consumer_porto will be register and handled by broker5
    - similar test with test_context_consumer_kaiserslautern, subscribes to broker3 for data in broker1

 - you can run tests by running the batch file run_test.bat

 - within the code, use the broker_logger.debug() function to see the inner workings
