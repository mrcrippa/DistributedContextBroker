Welcome to the Distributed Context Broker!

This project consists of the implementation of an initial prototype for a distributed context broker (a context information management and distribution server) using a P2P unstructured network. 

In the testing folder you can find scripts and config files to run a 5 broker network, as a small demo.

In the Peer-to-Peer Distributed Context Broker file, you can find more information about the overall concept and architecture for this project.
